# Локальный AWG 3.1 стенд

Использует ту же AmneziaWG-Go v3.1.20260814, что Windows DLL. Транспорт слушает
только 127.0.0.1 на случайном UDP-порту. TCP/UDP приложения живут в gVisor netstack
в памяти: системные адаптеры, маршруты и настройки VPN хоста не создаются.
VirtualBox NAT обращается к loopback хоста через 10.0.2.2.

Включены HeaderProtectionKey, S1–S4, диапазоны H1–H4, ContentPaddingAddition и
RandomTrailers. Проверка подтверждает передачу данных между Windows AWG и тестовым
peer; она не проверяет сервер провайдера или работу в сети с блокировками.

Первый stdout JSON содержит одноразовую клиентскую конфигурацию. Его разрешено
читать только в память запускающего скрипта, не выводить и не записывать в журнал.
Процесс завершается через три минуты либо раньше запускающим скриптом.
