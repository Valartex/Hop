# Публичные параметры Amnezia API

`amnezia.json` содержит публичный RSA-ключ шифрования запросов и адреса загрузки
посредников из официального Windows-дистрибутива 5.0.3.0. Это не API-ключ,
не приватный ключ, не подписка и не учётные данные. Извлечён статически без
запуска установщика и без чтения настроек установленной Amnezia.

Источник и SHA-256 дистрибутива/PEM сохранены в JSON. 14.10.2026 libagw 1.0.6
с этими параметрами расшифровал ответ публичного `v1/services`: код 0, 2 сервиса.
Проверка каталога не использовала ключ пользователя и не выдавала VPN-конфигурации.

Hop использует эти параметры из встроенного Qt-ресурса, когда production-параметры
не заданы при сборке. Dev-окружение не подменяется production-настройками.
Правоспособность подписки, квоты сервиса и доступность API проверяются отдельно.
