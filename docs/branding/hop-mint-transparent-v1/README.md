# Hop — прозрачный знак с мятной окантовкой

Основа: третий вариант с выносом из hop-options-extended-v1/03-hop-mint.svg.

Удалены фоновая плашка и её внешняя рамка. Внешний фон и свободное пространство внутри H прозрачны. Вокруг H добавлена тонкая окантовка, использующая тот же мятно-бирюзовый градиент, что был у подложки. Вокруг оранжевой траектории и в зазоре между ней и H сохранён существующий непрозрачный мятный градиент.

Форма H, её цвета, геометрия оранжевой дуги и её вынос не изменены. Толщина окантовки наружу составляет 0.6 в сетке 64×64, соответствует существующему зазору вокруг траектории.

- hop-mint-transparent.svg — прозрачный векторный знак.
- hop-mint-transparent-{256,512,1024}.png — прозрачные PNG.
- background-preview.png — демонстрация на трёх разных фонах; эти фоны есть только в листе сравнения.
- render.py — воспроизведение и проверка прозрачности.

Ресурсы приложения не заменены, малые кадры трея отдельно не адаптированы.
