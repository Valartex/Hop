# Hop — мультиразмерные иконки Windows

Три отдельных ICO на основе последних вариантов hop-mint-no-frame-v1: одинаковый мятный градиент, H с оранжевой траекторией и её выносом, без внешней рамки.

| Файл | Вариант |
|---|---|
| Hop-01-rounded.ico | №1, умеренное скругление |
| Hop-02-square.ico | №2, почти квадрат |
| Hop-03-soft.ico | №3, сильное скругление |

В каждом файле 15 кадров: **16, 20, 24, 30, 32, 36, 40, 48, 60, 64, 72, 80, 96, 128 и 256 px**.

Размеры покрывают перечисленные Microsoft размеры трея, заголовка, панели задач и Пуска при разных DPI; дополнительно включён 128 px. Источник: [Construct your Windows app's icon](https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-construction).

Все кадры имеют 32-битный цвет и альфа-канал. Кадры 16–128 px хранятся как BGRA DIB с AND-маской, 256 px — как PNG внутри ICO. Такая структура сохраняет прозрачные углы и позволяет Windows выбрать подходящий кадр. Каждый кадр отрисован непосредственно из SVG, а не увеличен из малого PNG. Геометрия выбранного оформления не менялась, отдельная оптическая модификация малых кадров не добавлялась.

## Содержимое

- Три файла *.ico — готовые мультиразмерные иконки.
- svg/ — точные копии исходных векторов.
- png/ — отдельные кадры каждого ICO.
- preview.png — кадры, прочитанные из готовых ICO: крупный вид и реальные размеры на светлом и тёмном фоне.
- verification.json — результаты проверки всех 45 кадров.
- build_icons.py — воспроизводимая сборка и проверка через локальный QtSvg и Win32.

## Проверки

Для каждого из 45 кадров:

- Qt обнаружил все предусмотренные размеры.
- Windows LoadImageW загрузила ICO в запрошенном размере, GetIconInfo подтвердил размеры и 32 bpp.
- После чтения из ICO альфа-канал побитно совпал с исходным растровым кадром.

Предпросмотр проверен визуально. Это проверка файлов и их загрузки средствами Windows, а не проверка работающего клиента в трее. Значки установленного приложения и ресурсы проекта не заменены.
