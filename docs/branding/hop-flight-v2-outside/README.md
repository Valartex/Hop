# Hop — концы траектории вне H

Два эскиза с мятной подложкой. Буква H и прямая перекладина сохранены из выбранного варианта hop-final-options-v1/03-hop-mint.svg. Оранжевая дуга начинается левее левого края H (x < 12) и заканчивается правее правого края (x > 52.05).

- 01-outside — начало x=7, конец x=57.
- 02-more-air — начало x=6, конец x=58; дуга немного выше.

Нет точек, полос или надписи. Зазор вокруг дуги совпадает с фоном. Скругление и подложка сохранены. Для каждого варианта есть SVG и PNG в 16/24/32/48/256/1024 px; comparison.png показывает оба варианта. Это эскизы траектории без отдельной оптической адаптации малых размеров. Предыдущие варианты и ресурсы приложения не заменены.
