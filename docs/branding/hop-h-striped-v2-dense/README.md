# Hop — частые горизонтальные прорези

Векторная доработка hop-h-striped-v1: вместо четырёх широких разрезов выполнено 35 частых тонких просветов, формирующих 36 полос, как у жалюзи. Оранжевая дуга остаётся цельной.

Форма H, оба фона, геометрия скруглённой плашки и прозрачные углы сохранены. Белой обводки нет: просветы и зазор вокруг дуги совпадают с фоном.

- 01-hop-background.svg и 01-hop-background-1024.png — мятно-бирюзовый фон Hop.
- 02-utorrent-green.svg и 02-utorrent-green-1024.png — зелёный фон выбранного ранее варианта.
- comparison.png — сравнение.
- render.py — воспроизводимое создание SVG и PNG через QtSvg.

Изменение выполнено непосредственно в векторной геометрии. Предыдущие эскизы и ресурсы приложения не заменены.
