# Hop — три мятных варианта без внешнего контура

Основа: варианты 1, 2 и 3 из hop-options-extended-v1. Четвёртый вариант в эту серию не включён.

Удалены оба слоя внешней рамки каждого значка. У всех вариантов теперь одинаковый мятно-бирюзовый градиент третьего варианта (#8CEBDD → #42BFC2). Геометрия подложки и её индивидуальное скругление сохранены. Зазор вокруг оранжевой дуги совпадает с новым фоном.

H, её прямая перекладина, оранжевый цвет и утверждённый вынос траектории не изменены. Прозрачные углы снаружи плашки сохранены.

- 01-mint-rounded.svg и PNG — умеренное скругление первого варианта.
- 02-mint-square.svg и PNG — почти квадратный второй вариант.
- 03-mint-soft.svg и PNG — сильное скругление третьего варианта.
- variants.png — общий лист сравнения.

Для каждого варианта сохранены прозрачные снаружи плашки PNG в 256/512/1024 px. render.py воспроизводит SVG/PNG и проверяет сохранение геометрии H и дуги. Ресурсы приложения и прежние эскизы не заменены.
