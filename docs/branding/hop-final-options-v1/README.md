# Hop — варианты финального оформления

Выбрана сплошная H с прямой перекладиной и оранжевой траекторией, без точек, надписи и горизонтальных прорезей. Основа: ../hop-h-teal-orange-v1/02-orange-trajectory.png. Геометрия отдельно воспроизведена в SVG для точных вариантов фона и скругления.

Применён установленный SVG Logo Designer. Его общие указания о минимуме 100 px и большом числе макетов не используются: по требованию пользователя нужен значок Windows и трея в 16–48 px.

## Варианты

| Номер | Файлы | Идея |
|---|---|---|
| 1 | 01-light-rounded.* | Светлая серо-голубая подложка #E1E9ED, тёмная H #073641, умеренное скругление. Основная рекомендация. |
| 2 | 02-light-square.* | Та же палитра, почти прямые углы. Показывает влияние формы плашки. |
| 3 | 03-hop-mint.* | Фирменный градиент #8CEBDD → #42BFC2 и сильное скругление текущего Hop. |
| 4 | 04-dark-rounded.* | Тёмная подложка #102932 и светлая H #E7F0F2; альтернативное выразительное оформление. |

Оранжевый цвет траектории во всех вариантах #EF862F. Прорезь вокруг неё совпадает с подложкой. Белой обводки вокруг траектории нет. У самой плашки тонкая двухцветная кромка: она помогает увидеть границу на светлом и тёмном окружении, не изменяя выбранную форму H.

## Читаемость на разных фонах

Все варианты имеют собственную непрозрачную плашку. Поэтому внешняя тема не просвечивает сквозь букву или зазор вокруг дуги и не меняет их внутренний контраст. Округлённые внешние углы прозрачны.

Это не обещание абсолютной различимости на произвольном пиксельном изображении: фон может совпасть с цветом кромки. При этом внутренний знак остаётся на фиксированной подложке. Вариант без подложки не предлагается как универсальный для разных тем, поскольку тёмная H теряет контраст на тёмном фоне.

Для 16/20/24 px используется отдельный micro SVG: знак увеличен на 10%, дальний конец траектории утолщён. Идентичность и пропорции H сохранены. Это оптическая адаптация малого размера.

## Файлы

- variants.png — крупное сравнение четырёх вариантов.
- backgrounds-and-sizes.png — светлое, тёмное, цветное и неоднородное окружение; реальные 16/24/32/48 px при масштабе изображения 100%.
- 16px-enlarged.png — кадры 16 px с увеличением в восемь раз без сглаживания.
- Каждый вариант: основной SVG, micro SVG, PNG в размерах 16/20/24/32/40/48/64/128/256/1024, ICO с девятью кадрами 16–256.
- render.py — воспроизводимый экспорт через существующий QtSvg.
- verification.json — результаты проверок непрозрачности плашки, прозрачности углов и сохранения оранжевых пикселей в малых кадрах.

ICO повторно прочитаны через QIcon; для каждого доступны все девять размеров. Листы сравнения просмотрены. Это файловая и визуальная проверка, а не проверка установленного клиента или реального трея Windows. Ресурсы приложения, сборка и установленная версия не заменены.
