# Hop — одинаковый вынос во всей серии

Вариантам 1, 2 и 4 из hop-final-options-v1 добавлена в точности та же траектория, что в утверждённом hop-mint-extended-v1/hop-mint-extended.svg. Фоны, H, перекладины, цвета и скругления каждого варианта сохранены.

Третий вариант не переделывался: SVG и PNG скопированы из готовой версии без изменений для удобства общего сравнения.

- variants.png — общий лист четырёх вариантов.
- 01-light-rounded.* — светлый, умеренно скруглённый.
- 02-light-square.* — светлый, почти квадратный.
- 03-hop-mint.* — уже готовый мятный.
- 04-dark-rounded.* — тёмная плашка, светлая H.

Для каждого варианта есть SVG и PNG в 256/512/1024 px. render.py воспроизводит файлы. Скрипт проверяет совпадение траектории во всей серии и неизменность геометрии H и плашек. Ресурсы приложения не заменены; отдельные кадры трея в этой итерации не создавались.
