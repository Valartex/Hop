# Hop — мятный заяц, мультиразмерная Windows-иконка

Готовый файл: **Hop-Rabbit-Mint.ico**. Основа — полностью мятный заяц и мятный хвост из ../hop-rabbit-colors-v1/01-rabbit-mint.png.

Характеристики совпадают с предыдущей оранжевой иконкой:

- 15 размеров: **16, 20, 24, 30, 32, 36, 40, 48, 60, 64, 72, 80, 96, 128 и 256 px**.
- 32-битный цвет, альфа-канал, прозрачный фон.
- Исходные пропорции сохранены, заяц вписан в квадратные кадры без растягивания и обрезки.
- Кадры 16–128 px — DIB с AND-маской; 256 px — PNG внутри ICO.
- Каждый кадр уменьшен отдельно из исходного большого PNG со сглаживанием в формате с предварительно умноженным альфа-каналом.

Все 15 кадров загружены средствами Windows LoadImageW и GetIconInfo; размеры и 32 bpp подтверждены. Qt прочитал весь набор, альфа-канал после чтения ICO точно совпал с исходными кадрами. preview.png просмотрен.

png/ содержит отдельные кадры, verification.json — результаты проверок, build_icon.py — воспроизводимую сборку. Исходные логотипы, прежняя иконка и ресурсы приложения не заменены.
