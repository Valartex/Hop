# Hop — мультиразмерная Windows-иконка с зайцем

Готовый файл: **Hop-Rabbit.ico**. Одна иконка на основе итогового оранжевого зайца из ../hop-rabbit-orange-v1/hop-rabbit-orange.png.

Содержит 15 размеров: **16, 20, 24, 30, 32, 36, 40, 48, 60, 64, 72, 80, 96, 128 и 256 px**. Все кадры 32-битные, с альфа-каналом. Фон прозрачный; пропорции, направление прыжка, хвост и цвет сохранены. Прямоугольный исходник вписан в квадратные кадры с прозрачными полями без растягивания и обрезки. Форма исходника не перерисовывалась.

Кадры 16–128 px сохранены как DIB с AND-маской, 256 px — как PNG внутри ICO. Каждый размер отрисован из большого исходного PNG отдельно. Сглаживание выполняется с предварительным умножением цвета на альфа-канал для корректного уменьшения прозрачных краёв.

## Проверки и вспомогательные файлы

- Windows LoadImageW и GetIconInfo успешно загрузили все 15 размеров, подтвердили их размеры и 32 bpp.
- Qt обнаружил все кадры; после чтения ICO альфа-канал каждого кадра точно совпал с исходным растровым кадром.
- preview.png — реальные кадры из ICO на разных фонах.
- png/ — каждый размер отдельно.
- verification.json — результаты проверок.
- build_icon.py — воспроизводимое создание и проверка иконки.

Значок установленного клиента и ресурсы приложения не заменены.
