# Hop — третий вариант с продлённой траекторией

Основа: hop-final-options-v1/03-hop-mint.svg, то есть именно третий вариант из указанного пользователем листа variants.png.

Сохранены H, прямая перекладина, фон, цвета, скругление и исходные кривые траектории внутри буквы. Добавлены только продолжения дуги слева и справа. Начало x=8 находится левее буквы (x=12), конец x=55.5 — правее неё (x=52.05). Это не высокая арка из последующих экспериментов.

Готовые файлы: hop-mint-extended.svg и PNG в 256/512/1024 px. Вектор воспроизводится render.py. Геометрия H и плашки проверена на идентичность исходному SVG. Малые кадры трея отдельно не адаптированы. Ресурсы приложения не заменены.
