# Hop — от ленты к ощущению полёта

Продолжение выбранного мятного варианта из hop-final-options-v1. Сохранены форма H, её прямая перекладина, градиент, плашка и скругление. Меняется только оранжевая траектория. Точки, текст и горизонтальные полосы не добавляются.

1. 01-high-arc — тонкая высокая дуга с заметным подъёмом и спуском. Дуга оставляет свободное место над перекладиной. Предлагаемое направление дальнейшей доводки.
2. 02-overflight — дуга проходит выше буквы и меньше пересекает её силуэт.
3. 03-takeoff — разрыв между начальным движением и основной дугой передаёт отрыв от опоры.

comparison.png показывает прежнюю ленту и три новых направления. small-sizes.png — реальные 16/24/32/48 px при просмотре в масштабе 100%. Это геометрические эскизы: тонкие дуги пока не имеют оптической адаптации для маленького трея, поэтому читать лист нужно как сравнение направления, а не готовые финальные ICO.

Для каждого направления сохранены SVG и PNG в 16/24/32/48/256/1024 px. Файлы воспроизводятся render.py через QtSvg. Векторная правка выполнена по workflow установленного SVG Logo Designer. SVG отрисованы и оба листа сравнения просмотрены. Предыдущие версии и ресурсы приложения не заменены.
