Три растровых эскиза, созданных встроенным image_gen. Продолжение поиска после отказа от отдельной дуги с двумя точками. Читаемость в реальном трее пока не проверялась.

1. 01-h-arch.png — H с симметричной дугой вместо перекладины.
2. 02-h-forward-hop.png — H с направленной слева направо дугой; рекомендуемое направление по выразительности движения.
3. 03-h-cutout.png — H с дугой-прорезью; прорезь может потеряться при уменьшении.
