# Проверка Amnezia, SMB и интерфейса, 21 октября 2026

Объём: замечания к установленной Windows 0.2.0.8. Кандидат 0.2.0.9.
Системные подключения выполняются только в Windows 10 VM через вручную запущенный
ограниченный агент. Сеть и другой VPN основного ПК не переключаются.

## Изменения

- В статусе соединения явно написано «Время ответа: … мс»; при отсутствии ответа
  используется отдельный текст. Это задержка ответа, не длительность подключения.
- Колонка индикатора и задержки локации имеет постоянную ширину 112 px. Текст
  «Не проверено» и числовой замер больше не меняют горизонтальное положение точки.
- Поля автопереключения называются «Длительность превышения, с» и «Порог задержки, мс».
  Пояснение описывает алгоритм без обозначений T1/T2. Компоновка учитывает ширину окна.
- Одиночный/общий замер поддерживает сохранённую API-конфигурацию соответствующей
  страны. Новые профили не выдаются; контейнеры подписки и её выбранная страна не меняются.
  DNS-подстановки конфигурации разрешаются перед запуском измерителя.
- Начавшийся отдельный замер удаляет прежний статус отключённой сессии этой локации,
  чтобы старый результат туннеля не перекрывал новый ручной/фоновый замер.
  Статус работающей активной сессии таким способом не сбрасывается.
- При работающем VPN отдельный AWG-измеритель не запускается, чтобы второй endpoint
  с тем же ключом не нарушал туннель. Для активной локации используется текущий туннель.
- Отказ API при подготовке подключения передаётся в сообщение интерфейса; одинаковая
  ошибка при переборе пула не вызывает повторное сообщение для каждой страны.
- Контроль активного туннеля повторяет одинаковый UDP DNS-запрос не более трёх раз
  за прежние восемь секунд и сопоставляет вопрос ответа с отправленным. Дополнительные
  признаки ответа остаются в stdout диагностического процесса, постоянный лог не включается.

## Что известно об API и слотах

Свежий read-only каталог возвращает для стран только поля `available_protocols`,
`server_country_code`, `server_country_code_l10n`, `server_country_name`.
Адресов endpoint в этом списке нет. В сохранённой модели есть конфигурация одной
страны, а не готовые конфигурации всех строк каталога.

Унаследованный `SubscriptionController::updateServiceFromGateway` генерирует новую
пару ключей при запросе конфигурации другой страны и вызывает `v1/config`.
Запрос сохранённого профиля для замера такого вызова не делает. Возможность
переиспользовать идентичность/получить адреса остальных стран без выдачи профилей
пока не подтверждена. Получение конфигураций всех стран ради статистики не реализовано.
Автоматическое удаление/отзыв пользовательских конфигураций не выполняется.

Файлов логов Hop в собственных Roaming/Local/ProgramData/ProgramFiles-каталогах
на основном ПК не найдено. Событий SMB Client Connectivity/Security за три дня
тоже нет. Причина прежней пользовательской ошибки по этим журналам не установлена.
