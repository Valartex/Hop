# Hop — статистика локаций и меню подписки

Запрос пользователя: убрать сведения/действия подписки из каждой локации;
добавить индивидуальную проверку времени ответа и график за период отслеживания.
Реализация 0.2.0.5 собрана и проверена. VM и основной ПК обновлены до 0.2.0.5.
На хосте GUI/VPN автоматически не запускались. Отчёт фактической замены:
windows-local-update-2026-10-19.md.

- Заголовки сгруппированы по ID сервиса, а не по совпадающему отображаемому имени.
  Их меню открывает сведения/обновление подписки. Меню локации содержит проверку
  ответа, статистику и членство в автопуле; сведений обо всей подписке там нет.
- EndpointHealthController умеет проверить один профиль, сохраняя прежние
  ограничения параллелизма и запрет второго AWG с тем же ключом при работающем VPN.
- Для API-страны без нового подключения/выдачи конфигурации используется только
  уже работающий туннель этой страны. Его существующие DNS-пробы идут в историю
  API-локации. У native-локаций — прежний endpoint-замер (HTTPS VLESS/AWG probe).
  Разные типы замеров в одной серии не смешиваются. Проверка не расходует слоты.
- История в памяти: до 240 точек на локацию за 24 часа, не более 8192 суммарно.
  Периоды: сеанс/15 минут/1/6/24 часа. Отмена/отложенные/unsupported не считаются
  сетевыми отказами. Удалённые локации удаляются из истории по catalogChanged.
- Qt Quick Canvas, без новой графической библиотеки: точки/линия для успешных
  ответов, красные отметки/разрывы при отказах, минимум/среднее/максимум и счётчики.
  В фоне история не сохраняется на диск; график перерисовывается только открытым.

Добавлены unit-проверки ограничений/статистики/периода, индивидуального вызова,
неучёта отмены, UI-истории/графика/меню.
