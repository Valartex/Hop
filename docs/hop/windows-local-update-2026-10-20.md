# Локальное обновление Hop 0.2.0.6

20 октября 2026, около 00:54 МСК. Обновление выполнено в рамках ранее разрешённой
установки полного клиента для пользовательской проверки. Дополнительный установщик
не разрабатывался. Hop.exe на основном ПК перед обновлением не был запущен;
туннельные процессы Hop также отсутствовали. Amnezia и сеть не переключались.

## Выполнено

После успешного RuntimeStage и GUI VPN-проверок AWG/BlancVPN в Windows 10 VM
подготовленный helper .research/update-local-hop-0.2.0.6.ps1 запущен с повышением
через штатный Windows UAC. Он проверил источник и пути, создал резервную копию,
заменил только Hop.exe и Hop-service.exe, запустил собственную службу и проверил IPC.
Весь локальный runtime из 198 файлов сверён по SHA-256.

- Каталог: `C:\Program Files\Hop`.
- Версия: `0.2.0.6`.
- Hop.exe: `d980ec5fa01dcedb885c6121ec104640561d4bd620560b953a71b55aca8531d4`.
- Hop-service.exe: `c9b958dbe7e0aba4aa1eb047e862f45187a52d0fff935dfbd76ee6dec8f5ff05`.
- Служба: Running, IPC pipe отвечает.
- networkUnchanged=true: совпал снимок маршрутов и DNS до/после обновления.
- amneziaServicesUnchanged=true: совпали состояния/PID/режимы служб Amnezia.
- GUI/VPN автоматически не запускались. Настройки и подписки пользователя
  не переносились из тестовой VM и не заменялись.

При Stop-Service старая 0.2.0.5 сообщила ошибку остановки, но уже находилась
в STOPPED. Helper проверяет это условие и лишь затем заменяет файлы. Новая служба
запущена, проверка IPC и всех файлов прошла. Обновление нельзя описывать как
полностью беспроблемную остановку старой службы; причина этого сообщения отдельно
не установлена. Событие не привело к изменению сети или откату файлов.

Результат: .research/local-hop-update-0.2.0.6-result.json (completed=true).
Backup прежних двух EXE и манифеста: .research/local-backup-before-0.2.0.6.
Подготовленный runtime: build/windows-local-0.2.0.6.

Запуск для пользовательской проверки — прежний ярлык Hop либо
`C:\Program Files\Hop\Hop.exe`. Текущая установка подтверждает файлы/службу/IPC;
она не является автоматическим сетевым тестом на основном ПК. Реальные VPN-тесты
этой сборки выполнялись только внутри VM.
