# Оформление Hop для Windows — 18 октября 2026

Пользователь попросил убрать бесполезный стартовый экран, заменить символику
и сведения о приложении, создать лаконичный логотип Hop и приблизить окна к
десктопному интерфейсу. Это отдельное явное уточнение интерфейса, без изменения
протоколов, маршрутизации, Kill Switch или установщика.

## Что изменено

- При пустом каталоге сразу открывается основной список подключений с кнопкой
  добавления. Экран «Приступим» не показывается в Windows Hop.
- Верхняя панель «Подключения / Настройки / Назад» заменяет нижнюю мобильную
  навигацию. Стандартная рамка Windows сохранена; окно изменяет размер,
  начальный размер 760 × до 680, минимум 640 × 480.
- Стиль стандартных контролов Fusion, шрифт Segoe UI, более компактные кнопки
  и отступы, диалоги с привычной панелью действий. Главная страница настроек
  использует обычные группы и флажки. Дополнительные страницы сохранены.
- Новый векторный знак: H и два узла сети. Бирюзовый акцент, тёмная основа.
  SVG — исходник; ICO содержит девять размеров 16–256, состояния трея различаются
  цветом. Значки EXE, окна, трея и основной страницы используют Hop.
- Метаданные EXE: FileDescription/ProductName/CompanyName — Hop,
  OriginalFilename — Hop.exe, LegalCopyright — Hop contributors.
- Собственная страница «О Hop» вместо рекламы/контактов/сайта исходного клиента.
  Ссылка на сайт в трее скрыта, рекламные предложения в окне импорта исключены.
  Подписи экспорта и резервных копий используют Hop.
- Название реального протокола AmneziaWG, данные импортированного провайдера,
  обязательные LICENSE и уведомления исходного кода сохранены. Реализация
  остальных платформ не выполнялась; десктопные изменения ограничены Windows Hop.

## Проверки и состояние VM

Пересборка прошла. Набор HopNativeDashboard прошёл с Fusion; усиленный сценарий
проверяет пустой каталог → основной экран → настройки → «О Hop» → основной экран
→ добавление HTTPS-подписки. Шесть сценариев плюс init/cleanup: 8 PASS.
В новом VM GUI-сценарии обязательны directDashboardStartup и desktopNavigation,
сохраняются отдельные снимки первого экрана, настроек и «О Hop» до ввода подписки.
