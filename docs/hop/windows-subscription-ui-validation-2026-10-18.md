# Подписки и единый интерфейс Hop — 18 октября 2026

Основание: пользовательская приёмка выявила одну строку Amnezia вместо локаций,
отказ 1108, бесполезную кнопку протокола, старую страницу «Сервис» и разное
оформление. Windows ещё не принята; предыдущие тесты не закрывают эти замечания.

## Каталог и подключение

Ранее ошибка подпроцесса или валидации молча оставляла одну строку подписки.
Пустой код автовыбора и повтор страны отклоняли весь список. Новый readApiCountries
пропускает отдельную запись автовыбора, объединяет протоколы одного кода страны
и проверяет размеры/типы. Ошибки видны пользователю, прежний список сохраняется.
Это дефекты обработки. После исправлений реальная подписка успешно вернула
53 локации в отдельном тесте только чтения; сырой ответ с данными аккаунта
в журнал не выводился.

LocationCoordinator публикует состояние каждого API-источника и обновляет
метаданные. Один источник можно обновить отдельно. ServiceInfo не возвращает
ключи или URL подписки: только имя, тип, число локаций, протокол, домен и счётчики.

1108 — ApiConfigLimitError. Теперь показываются смысл отказа и действия:
освободить ненужную конфигурацию у провайдера либо импортировать готовый файл.
Метка «Лимит подписки» не выдаётся за «Нет ответа» и измеренную задержку.
Автоматического удаления конфигураций нет. Внешний лимит исправлением текста
не снимается. Пользователь освободил слот; реальное подключение и HTTPS
подтверждены, полученная конфигурация сохранена в пользовательских настройках Hop.

## Аудит интерфейса

| Элемент | Решение |
| --- | --- |
| Верхняя навигация | Подключения / Настройки / Назад; вторые кнопки возврата на вложенных страницах убраны |
| Добавить | Ссылка/ключ или файл; неподдержанный на Windows QR больше не обещается |
| Обновить | Все подписки; в сведениях — один источник |
| Подключить / Отключить / Отмена | Основное действие рядом с состоянием и выбранной локацией |
| Протокол | Кнопка удалена; обычная подпись в карточке подключения |
| Маршруты | Общая политика VPN/Direct/Block и DAT для обоих протоколов |
| Автопереключение | Приоритеты локаций/стран, фиксация и исключения |
| Проверить | Задержка с прежними ограничениями безопасной проверки API/AWG |
| Локации | Группы по сервису, круглый переключатель одного выбора, состояние задержки, метки пула |
| В пул / Настроить / Сервис | Заменены меню «…»: сведения и включение/исключение из автопула |
| Сведения | Собственный HopServiceDialog без старой рекламной страницы |
| Настройки | Запуск, журналы, маршруты, резервная копия и «О Hop»; переходы к старым панелям скрыты |
| Импорт / резервная копия | Страницы Hop; восстановление с подтверждением и только без активного VPN |

HopStyle/HopButton/HopDialog задают общие цвета, размеры, рамки и панели действий.
Используются на основных страницах, в редакторе маршрутов, DAT, автопуле и сведениях.
Ошибки отличаются от рабочего состояния. Выбор файлов — штатный диалог Windows.

Подготовлен ограниченный VM-сценарий GuiCatalog. Обычный пользовательский процесс
читает свои сохранённые API-профили и ключи расшифрования только для чтения,

config/revoke/deactivate, настройки не записываются. Ключи/URL/JSON профиля не
попадают в результаты. Сохраняется проверка VirtualBox и ручного агента.
