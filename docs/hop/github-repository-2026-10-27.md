# Приватный репозиторий Hop

По запросу пользователя создан приватный репозиторий
https://github.com/Valartex/Hop в личной учётной записи Valartex.

- origin: https://github.com/Valartex/Hop.git.
- upstream: https://github.com/amnezia-vpn/amnezia-client.git.
- Рабочая ветка: codex/hop. История upstream сохранена; поверх неё добавлены
  исходники и ресурсы Hop, соответствующие проверенной 0.2.0.20.
- GPLv3, уведомления о сторонних компонентах и закреплённые submodule-коммиты
  сохранены. Исходный README upstream перенесён в docs/upstream/README.amnezia.md;
  основной README описывает Hop и ссылки на сборку.
- .tools, .research, build, журналы, файлы истории и учётные сведения не
  включаются в коммит. Перед загрузкой состав файлов проверен на случайные
  приватные ключи и токены. Обнаружены только строки парсера ключей в коде iOS.
- Унаследованный deploy.yml переведён с любого push на workflow_dispatch.
  Hop Windows CI также запускается вручную; релиз не создаётся.

Создание репозитория не меняет установленное приложение, службу или VPN.
