# Hop 0.2.0.1 — интерфейс и расписание обновлений, 19 октября 2026

Изменения выполняются по списку замечаний пользователя от 18/19 октября.
Системные проверки — только Windows 10 VirtualBox через вручную запущенный
ограниченный агент. Основной ПК и его Amnezia не перенастраивались.

## Что изменилось

| Замечание | Результат |
| --- | --- |
| Значок Amnezia в панели задач | Процесс имеет AppUserModelID Hop.Desktop; большому и малому значкам окна явно назначен Hop. В VM большой HICON прочитан через WM_GETICON и сопоставлен с Hop ICO. |
| Номер версии upstream | Отдельный hop/VERSION: 0.2.0.1. Видимая версия без upstream-хэша; PE FileVersion/ProductVersion тоже 0.2.0.1. |
| Неработающее меню «…» | QML Popup.Item поверх списка, явные цвета пунктов. «Сведения» открывает HopServiceDialog; второй пункт меняет участие в автопуле. |
| Верхнее меню | Левая панель: Подключения, Маршруты, Автопереключение, Настройки; О Hop внизу. |
| Маршруты в подключениях | Кнопка убрана; остаётся текст выбранного режима маршрутизации. Редактор доступен слева. |
| Автопереключение в подключениях | Кнопка убрана; прежний редактор вынесен на страницу слева. Общий компонент сохраняет прежнюю логику пула, стран и приоритетов. |
| Общее число локаций | Счётчик над списком удалён. |
| Автообновление подписок | Прежний скрытый интервал 6 часов заменён сохраняемой настройкой: вручную, 15/30 минут, 1/3/6/12/24 часа. Применяется к HTTPS и API-каталогам. |
| Обновление статуса локаций | Отдельная настройка: вручную, 1/5/10/30/60 минут. По умолчанию прежний ручной режим. Проверки ограничены по параллельности и не накладываются. |
| Категории настроек | Запуск, Автоматическое обновление, Данные приложения, Диагностика. |
| Поиск | Строка над списком; поиск по имени, сервису, протоколу и коду страны без учёта регистра. Фильтрация сохраняет исходные ID и правильный выбор строки. |
| Размер кнопок | Текстовые действия и пункты бокового меню 160×36; кнопки со значками — 36×36. |
| Дублирование NL/AE/… | Из подписи протокола убран ISO-код, из отображаемого имени — emoji-флаг, который Windows выводила двумя буквами. Исходные имена подписки и коды для автопула/поиска сохранены. |
| Невидимые пункты трея | Явные цвета QMenu для обычного, выбранного и недоступного пункта; значок Hop. Снимок реального меню VM читается, действие «Показать Hop» проверено нажатием. |

Периодические обновления выполняются при работающем Hop. Новый интервал статуса
не меняет отдельный контроль активного туннеля для автопереключения. AWG-пробы
откладываются при активном VPN; API-профили не выдаются ради измерения задержки.
Действующие конфигурации у провайдера не удаляются и не отзываются.

Общие HopStyle/HopButton/HopMenuItem и явная QML-палитра обеспечивают читаемость
независимо от системной светлой/тёмной темы. Нативная палитра QWidget применяется
отдельно к меню трея. Ненужная загрузка новостей Amnezia отключена для Hop:
она не имела доступного раздела и приводила к обращению фонового SDK-запроса
к уже уничтоженным настройкам в последовательной UI-регрессии.
