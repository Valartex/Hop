# Выбранный значок и плавный график задержки

Версия 0.2.0.16. Изменения ограничены интерфейсом и встроенными ресурсами клиента.

## Значок

По указанию пользователя client/images/hop/hop.ico побайтно заменён файлом
docs/branding/hop-windows-ico-v1/Hop-02-square.ico. SHA256 ICO:
835b058292357dd3c07c1ac5b35ce5a9f7d75d11e4fc4077913b4e8e2e2fa6d9.
В нативном ресурсе Windows проверены все 15 кадров: их содержимое совпало с ICO.
Проверка выполняется загрузкой PE как данных, без запуска приложения.
Скрипт/результат: .research/verify-0216-icon.py, .research/icon-0216-verified.json.

Окно, панель задач, уведомления и меню трея используют встроенный ICO. Сам значок
трея также загружает ICO через QIcon, чтобы сохранить выбор кадра по DPI.
Для UI взят соответствующий SVG Hop-02-square.svg; прямой QML Image с ICO
масштабировал первый кадр и давал размытие. Скрипт render-hop-icons.py теперь
копирует выбранные ICO/SVG, не пересобирая и не изменяя оригинальный ICO.
Из заголовка страницы подключений удалён повторяющийся логотип; знак в общем
боковом меню сохранён в выбранном оформлении.

## График

HopLatencyChart.qml отвечает за отрисовку, шкалы и наведение;
HopLatencyCurve.js — за геометрию. Монотонная кубическая интерполяция проходит
через представленные замеры, не добавляя выбросов за пределы соседних значений.
Нет ответа, одинаковое/обратное время и интервалы больше четырёх медианных
интервалов разрывают линию. Два замера соединяются отрезком, одиночный — точкой.

Добавлены пять подписанных уровней задержки с удобным шагом, шкала времени,
лёгкая заливка и просмотр времени/задержки замера при наведении. Красные отметки
обозначают отсутствие ответа. У коротких интервалов время содержит секунды,
у длинных — дату. Данные хранения, предел 240 точек и точные сводные показатели
по всем замерам не менялись. Новые строки переведены на RU/EN/ZH.
