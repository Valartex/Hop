# Очередь реализации

Текущий объём по решению пользователя: завершить Windows. Linux, macOS, Android и iOS отложены; их реализация и CI сейчас не входят в работу.

Уточнение 18 октября: этот roadmap составлен агентом и не заменяет согласование.
Установщик пользователь не просил; работы над ним остановлены. Сначала функциональная
готовность клиента по исходному ТЗ. Предложения в разделе выпуска не являются
обязательными работами без отдельного запроса пользователя.
Для первой Windows-версии согласованы IPv4 и блокировка IPv6, полный IPv6 не нужен.
Обход белых списков (исходный пункт 9) пользователь 18 октября перенёс в отдельный
отложенный этап. Он не блокирует завершение текущей Windows-версии; возвращаться
к реализации и проверке этого пункта только по отдельному согласованию.
Пункт 7 уточнён пользователем: требуется задержка в миллисекундах. Эта индикация
реализована. Пользовательская приёмка выявила проблемы API-каталога и интерфейса;
исправления прошли нативные проверки и реальные подключения в VM. Повторная
пользовательская оценка интерфейса ещё не выполнена; Windows не считать принятой.
Остальные открытые предложения не становятся обязательными автоматически.

19 октября по отдельному запросу пользователя установлен комплект для локальной
проверки на основном ПК: C:\Program Files\Hop, Hop-service и ярлыки. Проверены
файлы/служба/IPC и сохранение маршрутов/DNS/состояния Amnezia. VPN автоматически
не подключался; полноценная пользовательская проверка остаётся открытой. Это
разовая установка, работу над продуктовым MSI не возобновляли.
