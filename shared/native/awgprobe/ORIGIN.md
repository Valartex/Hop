# Проверка доступности AmneziaWG

Одноразовый процесс использует amneziawg-go/v3 v3.1.20260814 и пользовательский
netstack для проверяемого DNS-обмена внутри зашифрованного AWG-туннеля.
Адаптеры, драйверы, службы, DNS и маршруты операционной системы не меняются.
Полный профиль поступает только через stdin, результат содержит статус и задержку.

Одновременно запускается не более одной AWG-проверки. Перед началом рабочей
VPN-сессии она отменяется: повторное использование одного ключа может изменить
endpoint сервера. При активном VPN измерение AWG-кандидатов откладывается.
Неполученные API-профили не выпускаются автоматически ради диагностической проверки.

Задержка включает handshake и DNS-ответ; она не является измерением пропускной способности.
Проверяется только DNS-сервер профиля, входящий в его AllowedIPs. Профиль с несколькими
Peer или без проверяемого DNS-пути помечается неподдерживаемым для этой диагностики.
