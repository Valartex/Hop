# Hop

Мультипротокольный VPN-клиент на базе Amnezia VPN, C++ / Qt 6 / QML.
С 29 октября 2026 года разрабатывается Android-клиент с полным функционалом
Windows и адаптацией интерфейса под телефон. Платформенный код находится в
`platforms/windows` и `platforms/android`, переиспользуемые модули — в `shared`.
Обход белых списков сначала проходит приёмку на Android, затем переносится в Windows.
Исходники размещаются в приватном репозитории https://github.com/Valartex/Hop.
GPLv3 upstream сохранена. Это разработка, а не принятый публичный релиз.

## Сборка Windows

Локальные инструменты находятся в .tools: MSVC19.44, SDK10.0.26100,
Qt6.10.1 msvc2022_64, CMake3.31.10, Conan2.33, Ninja1.13.2, Go1.27.2, Zig0.17.0.
Скрипты изменяют окружение только своего процесса. .tools/.research/build — помощники
и артефакты разработки, не исходный код и не секреты для публикации.

```powershell
& hop/scripts/build-windows.ps1 -Tests -Targets Hop,Hop-service,hop_endpoint_probe,hop_tunnel_probe,hop_guard_recover,hop_windows_vpn_probe,test_http_subscriptions,test_location_catalog,test_selection_session,test_hop_dashboard,test_endpoint_health,test_route_datasets,test_traffic_policy,test_xray_lifecycle,test_windows_network_watcher
. hop/scripts/enter-build-env.ps1
ctest --test-dir build/windows/client/tests -R Hop --output-on-failure
& hop/scripts/stage-windows.ps1 -Destination build/windows-test -VmTests
```

Stage для разработки клиента: build/windows-test. Установщик отложен по требованию
пользователя; новые MSI не считать готовым выпуском. Прежний принятый пакет90ee
сохранён отдельно в .research/accepted-builds/90eeb429.
Системные VPN/WFP/SCM/драйверные тесты выполняются только через вручную запущенный
ограниченный Hop-VM-Agent внутри Windows 10 VM. Amnezia и сеть основного ПК не менять.
19 октября пользователь отдельно разрешил локальную установку файлов/компонентов
Hop для собственной проверки; она выполнена. Автоматические сетевые испытания
на основном ПК этим разрешением не добавлены; Amnezia не менять.

Предпросмотр общего QML без VPN: `python hop/preview/preview.py` (PySide6).
Нативные9HopCTest-наборов и независимые тесты находятся в client/tests и hop/tests.
Upstream: https://github.com/amnezia-vpn/amnezia-client, ветка dev.
